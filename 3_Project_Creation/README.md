# 3. Project Creation

This folder contains the project-management deliverables for the **Remote Patient Vitals Alert & Monitoring App** (Problem Statement #16).

## Deliverables

| File | Description |
|---|---|
| [`Kanban.pdf`](Kanban.pdf) | Jira Kanban deliverable showing the epic/story hierarchy, story points, an example of task and subtask creation with links, an initial board, and a mock workflow demonstration. |
| [`Scrum.pdf`](Scrum.pdf) | Jira Scrum deliverable showing the backlog, sprint planning, two simulated sprints, sprint progress, burndown charts, and reflection. |

The Scrum workflow is a **simulation** for demonstrating sprint planning and progress tracking; it is not a record of a real development team's velocity or capacity.
